# Warisan Nusantara

Warisan Nusantara adalah aplikasi pameran interaktif untuk kiosk layar sentuh vertikal di GIK UGM. Aplikasi dirancang offline-first untuk menjelajahi budaya dari 38 provinsi Indonesia.

## Fase Pengembangan Aktif

Fase saat ini berfokus pada konten **Batik**. Seluruh item Batik tetap berada di kategori universal `kain-tradisional`; kategori lain dipertahankan sebagai definisi tetapi belum diisi sampai pembaruan berikutnya.

Sebelum mengubah kode atau konten, baca dokumen berikut:

1. [Aturan wajib agen](AGENTS.md)
2. [Scope aktif Batik-first](docs/collaboration/CURRENT_SCOPE.md)
3. [Workflow dua perangkat](docs/collaboration/WORKFLOW_DUA_DEVICE.md)

Untuk memulai kedua perangkat tanpa menyusun prompt sendiri, buka [panduan mulai cepat](docs/collaboration/START_HERE.md).
